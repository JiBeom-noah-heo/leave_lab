## 무엇을 했나

위탁판매 상품을 수집하고, 걸러내고, 상품화해서 등록하는 파이프라인을 돌렸다. 작업은 AI 에이전트인 Claude Code에 맡겼고, 아래 숫자는 그 작업 기록에서 가져왔다. 결산은 두 번 했다. 한 번은 9월 11일, 한 번은 그로부터 2주 뒤다.

9월 11일 기준 숫자는 이렇다.

| 단계 | 건수 |
|---|---|
| 수집 | 1,321 |
| 제외 | 736 |
| 필터 통과 | 276 |
| 상품화 완료 | 171 |
| 등록 완료 | 137 (파이프라인 130, 외부 도구 7) |

파이프라인으로 등록한 130건의 마진 합계는 1,475,889원이었다. Python 파일 30개, 순수 함수 테스트 95건 규모였다.

제외된 736건은 사유별로 이렇게 나뉜다.

| 건수 | 사유 |
|---|---|
| 239 | 카테고리 불일치 |
| 195 | 용도 불일치 (캠핑·차량용 등) |
| 183 | 실마진 부족 |
| 57 | 중복 상품 |
| 49 | 니치 키워드 불일치 |
| 4 | 대량판매 단위 (박스) |
| 3 | KC 인증 필수 카테고리 |

수집한 상품의 절반 이상을 버렸다. 이 비율이 낮아지면 오히려 필터를 의심해야 한다고 기록해 두었다.

## 결과

2주 뒤 결산은 이렇게 바뀌었다.

| 항목 | 9월 11일 | 2주 뒤 |
|---|---|---|
| 수집 | 1,321건 | 12,519건 (9.5배) |
| 제외 | 736건 | 9,972건 |
| 상품화 완료 | 171건 | 1,989건 |
| 등록 완료 | 137건 | 538건 (3.9배) |
| 주문 | 0건 | 0건 |
| Python 파일 | 30개 | 36개 |
| 순수 함수 테스트 | 95건 | 291건 |

등록 완료된 538건의 마진 합계는 6,690,038원이다. 실제로 번 돈이 아니라, 팔렸다면 벌었을 돈이다. 주문이 0건이니 실제로 들어온 돈은 없다.

제외 사유 1위도 달라졌다. 9월 11일에는 카테고리 불일치(239건)가 1위였는데, 2주 뒤에는 니치 키워드 불일치(5,427건)가 1위가 됐다. 수집 경로가 엑셀에서 키워드 검색으로 옮겨가면서 관계없는 상품이 대량으로 딸려 들어왔기 때문이다. 시장가 초과(288건)라는 제외 사유도 새로 생겼다.

수집량과 등록량은 늘었지만 주문은 그대로 0건이다.
